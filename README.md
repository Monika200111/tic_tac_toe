# 🎮 Tic Tac Toe Game - JavaScript

A classic Tic Tac Toe game built with vanilla JavaScript, HTML5, and CSS3. Play against another player with a clean, responsive UI and real-time win detection.

**🔗 Live Demo:** [Play Now](https://monika200111.github.io/tic-tac-toe/)  
**💻 Tech Stack:** JavaScript · HTML5 · CSS3 · DOM Manipulation

---

### ✨ Features
- **2-Player Mode:** Play with a friend on the same device
- **Win Detection:** Automatically detects winner or draw state
- **Responsive Design:** Works smoothly on mobile, tablet, and desktop
- **Game Reset:** One-click restart for unlimited games
- **Clean UI:** Minimal, user-friendly interface with turn indicators

### 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Concepts Used:** DOM Manipulation, Event Handling, Game Logic, Win Algorithm
- **Deployment:** GitHub Pages
